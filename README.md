# Cafe Pomodoro ☕

A cozy cafe-themed Pomodoro timer extension for Visual Studio Code designed to help developers stay focused and take mindful breaks.

## Features

* **Focus Timer:** Set a dedicated focus session with cozy notifications.
* **Status Bar Integration:** Quick access and status updates right in your VS Code status bar.
* **Interactive Breaks:** Reminds you when it's time to take a sip of coffee and stretch!

## Requirements

* Visual Studio Code version `1.125.0` or higher.

## Usage

1. Open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P`).
2. Type **Start Cafe Pomodoro** and hit Enter.
3. Keep coding until your virtual coffee break notification arrives!
